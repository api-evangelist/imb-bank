# IMB Bank

> IMB Bank (IMB Ltd, ABN 92 087 651 974) is a member-owned Australian mutual bank founded in 1880, regulated by APRA and ASIC. Under Australia's Consumer Data Right (CDR / Open Banking) it is a data holder that exposes a public, unauthenticated Product Reference Data (PRD) API and an accredited consent flow for member banking data, via the IMB Innovation Sandbox and Marketplace.

## APIs

- [CDR Product Reference Data API](https://www.imb.com.au/openbanking): Public, unauthenticated CDR banking products API. Live base: https://openbank.openbanking.imb.com.au/cds-au/v1/banking/products (send x-v: 4). Operations listBankingProducts and getBankingProductDetail.
